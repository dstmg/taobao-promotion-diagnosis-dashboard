# 隐私与发布检查

## 输入与生成文件

- 输入表格只在本地读取，不通过网络发送。
- 生成 HTML 会把本次报表数据内嵌，以便离线交互；它可能包含商品名称、ID、金额和投放表现，应与源报表一样保管。
- 公开仓库与公开演示只允许使用 `examples/synthetic_reports/` 中的合成数据。
- 不把真实报表、生成报告、浏览器截图、日志、用户目录路径、凭据或商家标识放入仓库。

## 当前实现边界

- HTML 使用内嵌 CSS、JavaScript 和报告数据，不加载外部脚本、字体、图片或分析服务。
- 程序只读取用户指定的本地文件；不会解压到磁盘、登录广告账户、调用广告 API 或执行预算操作。
- ZIP、成员和行数均有大小限制。XLSX 使用 openpyxl 与 defusedxml；未启用安全 XML 解析时拒绝读取。
