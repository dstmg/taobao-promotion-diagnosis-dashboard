# 指标与关联口径

## 汇总规则

每个导入报表独立汇总。只有同一报表、同一统计窗口、同一粒度内的指标才可相加。不同维度报表可能是同一广告数据的不同切面，不能横向相加。

## 派生指标

| 指标 | 计算 |
| --- | --- |
| CTR | 点击量 / 展现量 |
| CPC | 花费 / 点击量 |
| 点击转化率 | 直接成交笔数 / 点击量 |
| 直接 ROI | 直接成交金额 / 花费 |
| 总 ROI | 总成交金额 / 花费 |
| 直接 CPA | 花费 / 直接成交笔数 |

除非来源数据明确提供零值，缺失保持为空。分母为零、缺失或不在同一粒度时显示不可计算。

如果分子字段没有导出，派生指标也保持不可计算，不把缺失值当作零成交。颜色提示只按已披露的数值规则标记异常；直接 ROI 的颜色分界为 1，表示直接成交金额是否覆盖广告花费，不代表毛利或盈亏。

未识别的数值列可作为自定义指标查看。列名包含比例、ROI、均值、单价、CPC 或 CPA 等特征时，界面按简单平均聚合并在列名标注“均值”；其他自定义数值列按求和聚合并标注“合计”。此为列名驱动的启发式口径，使用者应核对源字段含义；均值不代表按点击或曝光加权后的结果。

## 可关联范围

- 商品报表含主体 ID、主体名称、计划 ID、场景 ID 时，可以形成商品×计划×场景聚合。
- 关键词报表含宝贝 ID、计划 ID、场景 ID、单元 ID、词包/词名时，可按这些键过滤和查看。
- 地域、人群、创意、单元报表依赖各自真实包含的 ID；没有商品 ID 时不向商品层归因。
- 营销场景报表只有场景与日期时，只能用于场景层趋势。
- 只有名称时可做名称级探索，必须标注其稳定性低于 ID 关联。

## 建议边界

诊断优先描述数据事实与需要复核的候选项。报表归因周期、延迟成交、退款、成本、毛利、预算和库存信息不完整时，不输出确定的停投/加投或利润判断。
