## 已完成检查

- 项目按独立实现整理，没有复用千问、SGSkills 或其他第三方 Skill 的源码和素材。
- 输入与生成边界已写入 README、Skill 说明和隐私文档：只在本机读取；HTML 会内嵌本次数据；不登录广告账号、不调用平台接口、不上传数据。
- 样例 CSV 为合成数据。没有将真实报表、真实生成报告、截图、日志或个人路径放进项目样例。
- ZIP 不落盘解压，限制压缩包成员数、成员大小和解压后总大小。CSV/XLSX 按行读取并限制行数；单个直接输入文件在读取前检查大小。
- XLSX 在 `defusedxml` 安全解析未启用时拒绝读取。项目依赖版本固定，并提供第三方依赖说明。
- 指标检查确认比率在汇总后重算；零分母与缺失指标不伪装成数值 0；商品与计划关联使用精确 ID，同一数据不跨并列报表重复累计。
- 自定义指标按启发式规则标注“均值”或“合计”；均值不是加权均值，相关限制已在指标口径文档说明。
- 日期筛选会排除日期缺失的记录；报表缺少成交金额字段时不会生成“有花费但无成交”的错误诊断。
- 报表按来源维度独立展示。没有商品 ID 的地域、人群、场景等报表不会被推断成具体商品表现。
- `.gitignore` 排除输入文件、工作输出、表格和本地虚拟环境；`.gitattributes` 统一文本文件行尾；保留合成 CSV 与 HTML 模板。
- 项目吉祥物使用原创生成插画，已加入 README 并登记在第三方素材说明；未使用淘宝/天猫标识或 Robin 吉祥物。
